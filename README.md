# Data, study materials, analysis code, and models for Avatar Games study
- human_data contains data from the human experiments
    - human_data/study1 contains data from De Freitas et al. (2023)
-  human_experiment/ contains human experiment code adapted from De Freitas et al. (2023)
- src/ contains all code to run the computational models and analyses
    - Run src/run_exp.py to run the models on the avatar games
    - Run src/analysis/analyze.py to regenerate figures and results

 
De Freitas, J., Uğuralp, A.K., Oğuz-Uğuralp, Z., Paul, L.A., Tenenbaum, J., and Ullman, T. (2023). Self-orienting in human and machine learning. Nature Human Behavior. https://doi.org/10.1038/s41562-023-01696-5.
